\section{Project Overview}

A quick summary of the project aims:
Needs to provide counter examples for functions that do not work
Needs to be efficient to be able to handle large inputs and large numbers of inputs (Clustering)
How to match equivalent helper functions, how to find which functions are meant to be equivalent (Function Call Matching), this is done by finding functions with the same signature; with multiple functions with same signature, use tests to narrow down the search space, these test cases come from the counterexamples from candidate submissions, may need to reorder function arguments 
Using induction on the recursive structure of the functions
