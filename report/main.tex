\begin{abstract}
Two programs are equivalent if they produce the same output for any input. Proving program equivalence has applications across a variety of fields, however, these proofs are often difficult to write. This has led to the development of a variety of tools to help mitigate this \parencite{leinoDafnyAutomaticProgram2010,lahiriSYMDIFFLanguageAgnosticSemantic2012,IntroductionStainless091,cadarKLEEUnassistedAutomatic}, but using them still requires significant mathematical expertise that the average software developer does not have. The aim of this project is to decrease the necessity for this as much as possible, focussing specifically on the Dafny program verifier. In this project, I will explore Dafny's capabilities and limitations in proving program equivalence. I will build a tool on top of Dafny to attempt to remove these limitations and allow the user to create equivalence proofs with as little user assistance as possible. Finally, I will evaluate this tool against the current state-of-the-art systems.
\end{abstract}
