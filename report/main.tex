\begin{abstract}
Two programs are equivalent if they produce the same output for any input. Proving program equivalence has applications across a variety of fields, however, these proofs are often difficult to write. A variety of tools are being developed to make writing proofs easier, but using them still requires significant mathematical expertise that the average software developer does not have. The aim of this project is to decrease the level of user assistance needed to prove equivalence as much as possible, focussing specifically on the Dafny program verifier. In this project, I explored Dafny's capabilities in proving program equivalence. I built EquiDafny, a tool on top of Dafny to attempt to address the challenges the Dafny verifier faces. EquiDafny uses a novel algorithm called `Function Merging' to achieve this. By exploiting structural similarities between function bodies, the bodies can be split into their constituent parts and recursively `merged' together. This process is used to gather the information the Dafny verifier needs to prove equivalence. Finally, I evaluated EquiDafny against Dafny and Stainless. The results showed that EquiDafny improves upon the base Dafny verifier, though it is still less effective than the state-of-the-art checker Stainless.
\end{abstract}
