\begin{abstract}
Proving Program Equivalence is the act of verifying that, for any input, two programs always give the same output. If this can be proven, then these programs are described as equivalent. Program equivalence is a very important concept in Computer Science, with applications in a variety of fields. University lecturers can apply this to verify that student submissions to programming courseworks are equivalent to reference solutions. Compiler developers use this to ensure that optimisations do not change a program's behaviour. 

However, proving Program Equivalence is a very difficult task, especially since the problem is undecidable in general. Therefore, a variety of tools are being developed to help prove equivalence automatically. Using these tools makes proving equivalence significantly easier for developers, especially when working with large codebases. These tools can also generate counterexamples when equivalence cannot be proven, making debugging much easier. 

This project will focus on Dafny, a popular program verifier, under active development by Amazon. I will explore Dafny's capabilities and limitations in proving program equivalence. As detailed below, there are many cases where Dafny requires user assistance to complete its proofs. The aim of this project is to build techniques to allow Dafny to prove equivalence fully automatically, and to evaluate the new system against state-of-the-art tools.
\end{abstract}
