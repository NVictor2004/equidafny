This project raises very few ethical, legal, professional and societal issues. The only potential issue is that our tool must obey the licenses of the any third-party libraries or tools it uses. In particular, our tool must obey Dafny's MIT license, since Dafny will be used to verify the final equivalence lemmas. It must also obey Stainless's Apache 2.0 license\cite{StainlessFrontendsBenchmarks} and EqBench's MIT license\cite{badihiEqBenchDatasetEquivalent2021}, since these repositories will be used to form our evaluation testsuite.
